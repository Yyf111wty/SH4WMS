# 备刀机 — 小刀组盘出库托盘查询接口

## 1. 概述

小刀组盘出库完成后，备刀机扫描**大托盘条码**（或单个小托盘条码），调用本接口向 WMS 查询该托盘内的**盒子（小托盘）明细**及对应出库任务的 **workname（工单名称）**。

| 项目 | 说明 |
|------|------|
| 接口名称 | 组盘出库托盘信息查询 |
| 请求方式 | `POST` |
| Content-Type | `application/json` |
| 接口地址 | `{WMS_BillApi基地址}/api/wms/lygetpalletoutboundinfo` |

> `{WMS_BillApi基地址}` 以现场部署为准，例如：`http://192.168.x.x:端口`

## 2. 业务背景

1. 备刀机调用 `putoutbound` 申请小钻出库，WMS 生成出库任务并返回托盘列表。  
2. WCS 将各小托盘送至组盘台（出库口 `1002`），组盘完成后调用 `ReportPackingComplete` 上报大托盘号与小托盘列表。  
3. 大托盘流转至备刀机后，备刀机调用**本接口**获取托盘内全部盒子信息及工单名称 `workname`。

## 3. 请求参数

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| pallet | string | 二选一 | 大托盘条码（组盘完成上报的 `pallet`） |
| container | string | 二选一 | 小托盘/盒子条码（按单盒反查所属托盘及同盘其他盒子） |

**说明：** `pallet` 与 `container` 至少传一项；优先使用 `pallet` 查询整盘信息。

### 3.1 请求示例（按大托盘查询）

```json
{
  "pallet": "PALLET20240824001"
}
```

### 3.2 请求示例（按小托盘查询）

```json
{
  "container": "CTN00012345"
}
```

## 4. 响应参数

| 字段 | 类型 | 说明 |
|------|------|------|
| Success | bool | 是否成功 |
| Code | int | 0=成功，1=失败 |
| Message | string | 提示信息 |
| Result | object | 业务数据，失败时为 null |

### 4.1 Result 对象

| 字段 | 类型 | 说明 |
|------|------|------|
| workname | string | 出库任务工单名称（与 `putoutbound` 请求中的 workname 一致） |
| orderId | string | 订单号 |
| pallet | string | 大托盘条码 |
| boxCount | int | 托盘内盒子数量 |
| boxes | array | 盒子明细列表 |

### 4.2 boxes[] 元素

| 字段 | 类型 | 说明 |
|------|------|------|
| container | string | 小托盘/盒子条码 |
| specc | string | 规格编码 |

## 5. 响应示例

### 5.1 成功

```json
{
  "Success": true,
  "Code": 0,
  "Message": "查询成功",
  "Result": {
    "workname": "20260811220854394",
    "orderId": "20260811220854394",
    "pallet": "WHP16036",
    "boxCount": 12,
    "boxes": [
      {
        "container": "WH237375",
        "specc": "CX_UC-0.300B/5.5*M0"
      }
    ]
  }
}
```

### 5.2 未查到数据

```json
{
  "Success": false,
  "Code": 1,
  "Message": "未查询到组盘出库数据",
  "Result": null
}
```

### 5.3 参数缺失

```json
{
  "Success": false,
  "Code": 1,
  "Message": "参数 pallet 或 container 至少填写一项",
  "Result": null
}
```

## 6. 调用建议

1. **推荐时机：** WCS 组盘完成（`ReportPackingComplete`）且大托盘到达备刀机后，扫描大托盘条码调用本接口。  
2. **查询范围：** 仅返回小刀组盘出库任务（`TYPE=2`，目标出库口 `ENDTAXI=1002`，状态 `STATE>=2`）。  
3. **托盘复用：** 同一托盘条码可能多次参与组盘，接口按 `LASTEDITTIME` 取**最新一次**组盘批次（以 `PALLET + ORDERINFO` 标识），不会混入历史记录。  
4. **workname 用途：** 备刀机可根据 `Result.workname` 关联本地工单/加工程序。  
5. **重试：** 若组盘刚完成立即查询无数据，可间隔 1～2 秒重试（等待 WCS 上报落库）。  
6. **编码：** 请求与响应均为 UTF-8 JSON。

## 7. 相关接口

| 接口 | 说明 |
|------|------|
| `POST /api/wms/putoutbound` | 备刀机申请小钻出库 |
| `POST /api/wms/ReportPackingComplete` | WCS 组盘完成上报（WCS 调用） |
| `POST /api/wms/lygetcodelist` | 按条码批量查询规格 |
