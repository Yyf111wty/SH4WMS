# 旺宏·综合物流管理系统（WMS）操作手册

> 版本：PM1018  
> 适用对象：仓库操作员、班组长、系统管理员  
> 文档说明：本手册依据当前代码与页面结构整理，按钮以角色权限配置为准（不同账号可见按钮可能不同）。

---

## 1. 系统简介

**旺宏·综合物流管理系统**是一套面向自动化立体仓库的 WMS，主要功能包括：

- 入库 / 出库单据管理与 WCS 任务联动
- 库存查询与库龄预警
- 堆垛机、输送线、AGV 任务监控
- 仓库、库区、库位等基础数据维护
- 用户、角色、权限管理
- 竞标 / 报价业务（BIDD 模块，按需启用）

系统采用 **Layui** 界面框架，左侧菜单按用户权限动态加载。

## 2. 快速登录与界面说明

### 2.1 登录

1. 打开浏览器，访问系统登录页：`/Login/Index`
2. 输入 **用户名**、**密码**
3. 登录成功后进入主界面 `/Home/Index`

> 若长时间未操作或 Token 失效，系统会自动跳回登录页。

### 2.2 主界面布局

| 区域 | 说明 |
|------|------|
| 顶部导航 | 一级模块切换（如 WMS、系统管理、竞标等） |
| 左侧菜单 | 当前模块下的功能页面 |
| 内容区 | 以 Tab 页签形式打开各功能页面 |
| 右上角 | 全屏、修改密码、退出登录 |

### 2.3 常用操作

- **打开功能**：点击左侧菜单项，在 Tab 中打开对应页面
- **关闭 Tab**：点击 Tab 上的 ×
- **修改密码**：右上角用户菜单 → 修改密码
- **退出**：右上角 → 退出

### 2.4 页面通用元素

多数业务页面包含：

1. **查询条件区**：输入/下拉筛选后点击「查询」
2. **工具按钮区**：由权限控制（新增、编辑、删除、查询、下发等）
3. **数据表格**：支持排序、分页；部分页面为主从表（点击主表行加载明细）

## 4. 核心业务操作

### 4.1 入库清单

**路径**：WMS → 入库清单（`/WMS/PutIn/Index`）

#### 功能说明

管理入库绑定单据及其物料明细，并与 WCS 入库任务联动。

#### 查询条件

| 字段 | 说明 |
|------|------|
| 库区 | 下拉选择 |
| 单据编号 | 来源单号 |
| 载具编号 | 托盘/载具号 |
| 分配库位 | 系统分配的库位 |
| 物料编号 / 批次 | 明细筛选 |
| 请求入库标识 | 未请求 / 已请求 |
| 状态 | 待执行 / 正在执行 / 已完成 |
| 有效标识 | 有效 / 失效 |
| 时间范围 | 创建或业务时间 |

#### 主表关键字段

- **单据编号、载具编号、分配库位、目标地址**
- **状态**：0 待执行 → 1 正在执行 → 2 已完成
- **请求入库标识**：0 未请求 → 1 已请求（已向 WCS 发起）
- **有效标识**：失效单据不参与业务

#### 明细表

点击主表某行，右侧/下方显示 **物料绑定明细**（物料编号、批次等）。

#### 典型操作流程

```
创建/接收入库单 → 绑定物料明细 → 请求入库（下发 WCS）
→ 堆垛机/输送线执行 → 状态变为「已完成」
```

> 若单据异常，具备权限的用户可使用「重置」类按钮将状态恢复为待执行（`STATE=0`，`QUESTFLAG=0`），具体以页面按钮为准。

---

### 4.2 出库清单

**路径**：WMS → 出库清单（`/WMS/PutOut/Index`）

#### 功能说明

管理出库任务，跟踪从库位到目标地址的搬运过程。

#### 查询条件

与入库类似，另含 **目标地址** 筛选。

#### 状态说明

| 状态值 | 含义 |
|--------|------|
| 0 | 待执行 |
| 1 | 正在执行 |
| 2 | 已完成 |
| 3 | 已装盘 |
| 5 | 异常结束 |

#### 主从表

- 主表：出库绑定主表（库区、单据、载具、起始地址、目标地址等）
- 明细：物料编号、批次

#### 典型操作流程

```
创建出库单 → 系统分配库位/载具 → 下发 WCS 任务
→ 堆垛机取货 → 输送线/AGV 转运 → 完成出库
```

---

### 4.3 库存报表

**路径**：WMS → 库存报表（`/WMS/Inventory/Index`）

#### 功能说明

按库位维度查询当前库存，支持库龄预警。

#### 查询条件

- 库位编号、库位状态、载具编号、单据编号
- 排 / 列 / 层 / 巷道
- 时间范围
- **预警天数**（默认 7 天）：用于标识超期库存

#### 库位状态

| 状态 | 含义 |
|------|------|
| 空库位 | 无货 |
| 空托盘 | 有空载具 |
| 有库存 | 有物料 |
| 冻结站台 | 不可用 |

#### 使用建议

- 班组长每日查看「有库存」+ 预警天数，处理呆滞物料
- 结合 **巷道、排列层** 定位物理位置

---

### 4.4 堆垛机任务

**路径**：WMS → 堆垛机任务（`/WMS/StockerTask/Index`）

#### 功能说明

监控堆垛机（Stocker）任务执行情况。

#### 查询条件

- 单据编号、载具编号
- 库区（101-1 原材料 / 201-1 半成品 / 301-1 成品 / 401-1 冷藏）
- 任务起点 / 终点
- **任务类型**：1 入库 / 2 出库 / 3 移库
- **任务状态**：待执行 / 正在执行 / 已完成 / 已装盘 / 异常

#### 操作建议

- 入库/出库异常时，先在此页查堆垛机任务是否卡在「正在执行」或「异常」
- 与 **入库清单 / 出库清单** 对照单据编号排查

---

### 4.5 输送线任务

**路径**：WMS → 输送线任务（`/WMS/ConveryTask/Index`）

#### 功能说明

查看输送线搬运任务（开始位置 → 结束位置）。

#### 常用筛选

单据编号、载具编号、开始/结束位置、任务状态。

---

### 4.6 AGV 任务

**路径**：WMS → AGV 任务（`/WMS/AgvTask/Index`）

#### 功能说明

监控 AGV 搬运任务（开始位置、终点位、优先级、状态）。

---

### 4.7 报工信息

**路径**：WMS → 报工信息（`/WMS/ReportWork/Index`）

#### 功能说明

记录 WCS/WMS 交互结果，含载具、单据、库位、成功标记、任务类型等，用于追溯设备执行反馈。

---

### 4.8 入库测重

**路径**：WMS → 入库测重（`/WMS/Weigh/Index`）

#### 功能说明

管理入库称重相关数据（与称重设备或接口对接，具体字段以页面为准）。

---

### 4.9 巷道开关管理

**路径**：WMS → 巷道开关管理（`/WMS/Lane/Index`）

#### 功能说明

按 **巷道编号** 查看当前启用状态，并可切换巷道开/关。

#### 操作步骤

1. 页面加载后自动列出所有巷道及状态
2. 点击对应操作按钮切换状态
3. 系统先调用 WCS 接口，成功后更新库位表 `wms_base_location.ENABLED`

> **注意**：关闭巷道会影响该巷道内库位的可用性，操作前请确认现场无进行中的堆垛机任务。

## 5. 基础数据维护

### 5.1 仓库管理

**路径**：WMS → 仓库管理（`/WMS/Warehouse/Index`）

维护工厂编码、仓库编号、仓库名称、入库/出库原则、有效标识等。

### 5.2 库区信息

**路径**：WMS → 库区信息（`/WMS/Zone/Index`）

维护库区与仓库的从属关系及基本属性。

### 5.3 库位管理

**路径**：WMS → 库位管理（`/WMS/Location/Index`）

#### 主要字段

- 库区、库位编号、库位类型（ST 存储位 / PT 其他）
- 载具、单据、排/列/层/巷道、限高
- 库位状态、有效标识

#### 常见操作

- **查询**：按条件定位库位
- **新增 / 编辑 / 删除**：需相应权限
- 库位状态变更会影响 WCS 分配逻辑，请谨慎操作

### 5.4 物料信息

**路径**：WMS → 物料信息（`/WMS/Master/Index`）

维护物料规格、库存状态（库存充足 / 库存不足）等主数据。

- 右侧：用户关联角色

## 8. 典型业务场景速查

### 场景 A：物料入库

1. 确认 **物料信息** 已维护
2. 在 **入库清单** 创建/确认入库单及物料明细
3. 执行「请求入库 / 下发」
4. 在 **堆垛机任务**、**输送线任务** 跟踪执行
5. 在 **库存报表** 确认库位状态为「有库存」

### 场景 B：物料出库

1. 在 **出库清单** 创建/确认出库单
2. 下发 WCS 任务
3. 跟踪 **堆垛机任务** → **输送线/AGV 任务**
4. 确认出库状态为「已完成」或「已装盘」

### 场景 C：任务卡住排查

1. **入库/出库清单** 查单据状态
2. **堆垛机任务** 查是否异常
3. **报工信息** 查 WCS 反馈
4. **库位管理** 查库位是否冻结
5. **巷道开关** 查巷道是否被关闭

### 场景 D：新用户上岗

1. 管理员创建用户并分配组架
2. 在 **角色权限** 中配置菜单与按钮
3. 用户登录验证可见菜单与可操作按钮
4. 操作员仅需关注本库区相关页面

## 10. 常见问题（FAQ）

**Q1：登录后左侧菜单为空？**  
A：当前用户未分配任何页面权限，请联系管理员在「角色权限」中配置。

**Q2：看不到「新增」「下发」等按钮？**  
A：按钮级权限未分配。管理员需在「权限维护」中确认按钮已配置，并在「角色权限」中勾选。

**Q3：入库单一直「待执行」？**  
A：检查是否已「请求入库」、WCS 是否在线、巷道是否关闭、库位是否可用。

**Q4：库存与实物不符？**  
A：查报工信息、堆垛机任务是否异常结束；必要时由管理员在库位管理或后台处理。

**Q5：如何限定用户只看某个库区？**  
A：使用专用账号（ycl/bcp/cp/lck）或在数据权限层扩展；当前代码对四类库区账号做了自动过滤。

## 11. 附录：如何快速更新本手册

若系统功能变更，建议按以下步骤同步手册（约 1～2 小时）：

1. **梳理菜单**：从数据库 `sys_permissions` 或「权限维护」页导出模块/页面列表
2. **逐页截图**：每个 Index 页面截图（查询区 + 按钮 + 表格），存入 `docs/images/`
3. **对照代码**：Views 中 `layui-card-header` 为页面标题；`<select>` 和表格 `title` 为字段说明
4. **按钮清单**：查 `loadgroupformbutton.js` 及 `GetPermissionBtn` 返回的 NodeName
5. **业务流程**：对照 Controller 与 WCS 接口（如 `WCSService.cs`、`WmsController.cs`）
6. **评审**：请现场操作员走查一遍，补充 FAQ
